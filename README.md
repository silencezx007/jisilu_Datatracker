# LOF Hunter - LOF 溢价套利监控系统

自动化监控集思录 LOF 基金数据，筛选高溢价且限购的套利机会，通过微信推送提醒。

## 功能特性

### 核心功能
- ✅ **自动数据爬取**: 通过集思录 API 获取实时 LOF 基金数据
- ✅ **智能筛选**: 自动过滤溢价率 > 2% 且申购状态包含'限'字的基金
- ✅ **定时任务**: 使用 node-cron 实现定时监控（默认每日 14:45）
- ✅ **微信推送**: 通过 Manus Notification API 向项目所有者发送套利机会提醒
- ✅ **历史记录**: 存储每日监控数据，支持查询历史套利机会
- ✅ **推送日志**: 记录每次推送的时间、基金数量和详细内容

### Web 界面
- **基金列表页面**: 移动端友好的基金列表展示，按溢价率降序排列
- **配置管理页面**: 后台管理界面，支持配置监控规则（溢价率阈值、触发时间等）
- **推送历史页面**: 查看历史推送记录和详细内容

## 技术栈

### 后端
- **框架**: Express + tRPC
- **数据库**: MySQL/TiDB (Drizzle ORM)
- **定时任务**: node-cron
- **数据爬取**: axios
- **推送服务**: Manus Notification API

### 前端
- **框架**: React 19 + Wouter
- **UI 组件**: shadcn/ui + Tailwind CSS 4
- **状态管理**: TanStack Query (通过 tRPC)

## 使用指南

### 查看套利机会

访问首页即可查看最新的套利机会列表。每个基金卡片显示：
- 基金名称和代码
- 溢价率（绿色徽章）
- 现价和净值
- 申购状态
- 基金公司

### 配置监控规则

1. 点击导航栏的"配置管理"
2. 点击"新建配置"按钮
3. 设置以下参数：
   - **配置名称**: 便于识别的名称
   - **溢价率阈值**: 只监控溢价率大于此值的基金（默认 2%）
   - **定时任务**: Cron 表达式，支持多个时间点（用逗号分隔）
     - 默认: `45 14 * * *` (每日 14:45)
     - 示例: `45 14 * * *,0 10 * * *` (每日 14:45 和 10:00)
   - **启用状态**: 是否启用此配置

### 查看推送历史

访问"推送历史"页面可以查看：
- 推送时间
- 推送状态（成功/失败）
- 符合条件的基金数量
- 详细的基金列表

### 手动触发监控

在首页点击"立即监控"按钮可以手动触发一次监控任务，无需等待定时任务。

## 定时任务说明

### Cron 表达式格式

系统使用 6 字段 Cron 表达式：

\`\`\`
秒(0-59) 分(0-59) 时(0-23) 日(1-31) 月(1-12) 周(0-6)
\`\`\`

### 常用示例

- `45 14 * * *`: 每日 14:45
- `0 10,14 * * *`: 每日 10:00 和 14:00
- `0 9-17 * * 1-5`: 工作日每小时（9:00-17:00）
- `*/30 * * * *`: 每 30 分钟

### 多时间点配置

支持在一个配置中设置多个监控时间，用逗号分隔：

\`\`\`
45 14 * * *,0 10 * * *,30 15 * * *
\`\`\`

## 数据库表结构

### lof_records (LOF 基金监控记录)
存储每次监控扫描到的符合条件的基金数据。

### monitor_configs (监控配置)
存储监控规则和定时任务配置。

### push_histories (推送历史)
记录每次推送的详细信息。

## API 接口

### LOF 相关
- `lof.getLatest`: 获取最新的 LOF 记录

- `config.create`: 创建新配置（需要管理员权限）
- `config.update`: 更新配置（需要管理员权限）

### 推送历史
- `history.getAll`: 获取推送历史

## 常见问题

### Q: 为什么没有收到推送通知？

A: 可能的原因：
1. 当前没有符合条件的套利机会（溢价率 > 2% 且限购）
2. 定时任务尚未触发（检查配置的 Cron 表达式）
3. 查看推送历史页面确认推送状态

### Q: 如何修改溢价率阈值？

A: 在配置管理页面创建新配置或更新现有配置，设置所需的溢价率阈值。

### Q: 定时任务什么时候执行？

A: 默认配置为每日 14:45（收盘前 15 分钟）。你可以在配置管理页面修改 Cron 表达式来调整执行时间。

### Q: 数据从哪里来？

A: 数据来自集思录（Jisilu）的公开 API 接口，实时获取 LOF 基金的价格、净值、溢价率和申购状态等信息。
